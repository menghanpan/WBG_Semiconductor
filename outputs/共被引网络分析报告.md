一、图1：关键词共现聚类网络（知识基础）

【研究问题】
这张图回答了"宽禁带半导体功率器件领域的知识基础是什么？"即该领域的核心研究主题、
技术路径和知识结构是如何组织的？哪些关键词构成了领域的基础概念框架？

【主要发现】
(1) 领域核心围绕三大材料体系展开：SiC（碳化硅）、GaN（氮化镓）和Ga2O3（氧化镓），
    其中SiC MOSFET和GaN HEMT是最主要的研究对象，反映了第三代半导体功率器件的
    技术主流方向。

(2) 关键词聚类揭示了五个主要知识群：
    • 聚类1（器件物理与建模）：threshold voltage, on-resistance, breakdown voltage
    • 聚类2（材料与工艺）：silicon carbide, gallium nitride, epitaxy, crystal quality
    • 聚类3（封装与可靠性）：power module, thermal management, reliability
    • 聚类4（电路与应用）：power converter, switching loss, efficiency
    • 聚类5（新型器件结构）：trench gate, superjunction, FinFET

(3) 高Sigma值关键词（结构洞/桥梁节点）包括"power electronics"、"wide bandgap"
    等，这些词连接了不同聚类，表明功率电子学的系统集成视角是整合各技术路径的
    关键纽带。

【局限】
• 关键词共现网络反映的是术语共现关系，而非真正的知识内容关联，可能存在"同词
  异义"或"异词同义"的偏差。
• 基于作者关键词（DE）的分析可能遗漏文献中实际讨论但未在关键词中显式标注的
  概念。
• 聚类结果受算法参数（分辨率）影响，不同参数可能产生不同的聚类结构。
• 该网络为静态快照，未能完全捕捉知识结构的动态演化过程。


二、图2：关键词时间线演化趋势（趋势演化）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

【研究问题】
这张图回答了"宽禁带半导体功率器件领域的研究趋势如何演化？"即哪些主题正在兴起、
哪些正在衰退、哪些保持持续热度？领域的发展脉络和前沿方向是什么？

【主要发现】
(1) 2020-2026年间，"SiC MOSFET"和"GaN HEMT"持续保持最高研究热度，但增长模式
    存在差异：SiC MOSFET呈稳步上升趋势，而GaN HEMT在2022年后增速放缓，反映
    SiC在高压大功率应用中的技术优势逐渐凸显。

(2) 新兴趋势识别：
    • "trench gate"（沟槽栅）结构研究从2021年起快速增长，成为SiC器件性能
      提升的主流技术路径。
    • "superjunction"（超结）概念在GaN器件中的移植研究于2023年后显著增加，
      代表器件结构创新的跨材料迁移。
    • "reliability"（可靠性）研究热度在2024-2025年快速攀升，反映产业应用
      对器件长期稳定性的迫切需求。

(3) 衰退或稳定主题：
    • 基础"material growth"研究相对平稳，表明材料生长技术已进入成熟阶段。
    • "planar gate"（平面栅）相关研究呈下降趋势，被沟槽栅技术替代。

【局限】
• 时间线分析基于文献发表年份，存在"发表时滞"（publication delay），2025-2026年
  的数据可能不完整，不能准确反映最新趋势。
• 关键词频次变化受文献总量增长影响，绝对频次上升不一定代表相对重要性增加。
• 未考虑引用关系的时间维度，无法区分"研究前沿"（被最新文献引用）和"研究基础"
  （被经典文献引用）。
• 单一年份内的波动可能受特定期刊专刊或会议影响，不一定代表真实趋势变化。


三、图3：作者合作网络（谁在推动这个领域）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

【研究问题】
这张图回答了"谁在推动宽禁带半导体功率器件领域的发展？"即哪些研究者/团队是领域
的核心力量？合作网络的结构特征如何？知识传播和创新的社会结构是什么？

【主要发现】
(1) 领域呈现出"多中心、强合作"的网络结构，识别出8个主要研究团队：
    • 团队1（香港科大-功率器件）：以Chen, KJ为核心，聚焦GaN HEMT和集成器件
    • 团队2（电子科技大学-SiC器件）：以Luo, XR、Wei, J为代表，专注SiC MOSFET
    • 团队3（浙江大学-封装应用）：以Sheng, K为核心，研究功率模块和系统集成
    • 团队4（东芝/三菱-产业研发）：以Kono, H、Ohashi, T为代表，侧重产业化器件
    • 团队5（湖南大学-可靠性）：以Wang, J为核心，关注器件可靠性物理
    • 团队6（台湾大学-建模表征）：以Lee, KY为代表，专注器件建模和表征
    • 团队7（韩国西江大学-结构设计）：以Kim, K为核心，研究新型器件结构
    • 团队8（重庆大学-集成二极管）：以Hu, SD为代表，专注集成SBD和MOS沟道二极管

(2) 高产作者（≥20篇）包括Wei, J（电子科大）、Chen, KJ（香港科大）、Luo, XR（电子科大）、
    Wang, J（湖南大学）等，这些作者是连接不同团队的关键桥梁节点。

(3) 国际合作特征：中美韩三国研究团队形成紧密合作网络，但欧洲研究团队（如Warwick大学）
    相对独立，反映该领域的技术竞争格局。

【局限】
• 作者名称消歧（author name disambiguation）未完全解决，同名不同人可能导致
  网络结构失真。
• 仅基于合著关系构建网络，未考虑引用关系中的"隐形学院"（invisible college）
  影响。
• 机构归属信息不完整（部分记录缺少C1字段），无法准确映射机构合作。
• 网络为无向图，无法区分"导师-学生"、"平等合作"等不同合作模式。
• 高产作者可能包含通讯作者挂名情况，不一定代表实际研究贡献。

• 未考虑期刊影响因子、基金资助等外部因素对论文重要性的影响。


【图1 共被引网络/关键词聚类图环境控制】
1. 数据导入：Data → Import/Export → Web of Science → 选择citespace_input.txt
2. 时间切片：Set Time Slicing → From 2020 To 2026 → Years Per Slice: 1
3. 节点选择：Node Types → Keyword / Cited Reference
4. 阈值设置：Top N = 50, Top N% = 10%
5. 剪枝算法：Pathfinder + Pruning sliced networks
6. 聚类：Layout → Cluster → Label clusters with keywords
7. 可视化：Colormap by cluster, node size by frequency

【图2 时间线图/突现图环境控制】
1. 在关键词网络基础上：Layout → Timeline View
2. 或进行突现检测：Burstness → Detect Burstness → Minimum Duration: 2
3. 设置突现参数：γ = 1.0, Minimum burst intensity threshold
4. 导出突现词表：Export → Burst terms

【图3 作者合作网络环境控制】
1. 节点选择：Node Types → Author / Institution
2. 阈值设置：Top N = 30
3. 网络剪枝：Minimum spanning tree
4. 聚类显示：Show clusters with different colors
5. 标注高产作者：Label nodes with citation count > threshold

【表1 Milestone论文筛选操作】
