## 图1: 文献共被引网络图 / 关键词聚类图

### 研究问题
**知识基础是什么？** —— 该领域依赖哪些奠基性文献？研究主题如何聚类？

### 解读框架（≥200字）

```markdown
#### 主要发现
1. **聚类结构**: 网络被划分为 X 个主要聚类（Modularity Q = XX, Silhouette S = XX），
   表明领域知识结构清晰/较为分散。

2. **核心聚类**: 
   - 聚类 #0（标签: XXX）: 规模最大，主要关注 XXX，代表该领域的核心知识基础。
   - 聚类 #1（标签: XXX）: 涉及 XXX，反映 XXX 方向的研究积累。
   - 聚类 #2（标签: XXX）: 与 XXX 相关，显示跨学科/新兴方向。

3. **关键节点**（高中心性文献）:
   - [作者, 年份]: 中心性 XX，是该领域的知识桥梁，连接了 XXX 和 XXX 两个方向。
   - [作者, 年份]: 被引频次最高（XX次），奠定了 XXX 的理论基础。

4. **时间特征**: 聚类平均年份集中在 20XX–20XX，表明知识基础以近 X 年文献为主，
   领域处于快速发展期/成熟期。

#### 局限
- 共被引分析反映的是"被谁引用"而非"引用谁"，可能遗漏最新但尚未被广泛引用的新兴文献。
- 聚类标签依赖算法提取，需结合人工判读验证准确性。
- g-index=25 的阈值设置可能过滤掉部分小众但重要的研究方向。
```

## 图2: 时间线图 / 突现图

### 研究问题
**趋势如何演化？** —— 研究主题随时间如何变迁？哪些方向正在兴起或衰退？

### 解读框架（≥200字）

```markdown
#### 主要发现
1. **演化路径**: 从时间线视图可见，领域发展呈现以下阶段特征：
   - **2020–2021**: 早期研究集中于 XXX（聚类 #X），以 XXX 为主要议题。
   - **2022–2023**: XXX 方向兴起（聚类 #X），反映 XXX 技术突破带来的研究转向。
   - **2024–2026**: XXX 成为新兴热点（聚类 #X），预示未来发展方向。

2. **突现词分析**:
   - **持续突现**: "XXX"（20XX–20XX）持续保持高突现强度，表明 XXX 是长期核心议题。
   - **新兴突现**: "XXX"（20XX–20XX）突现强度达 XX，标志 XXX 成为最新研究前沿。
   - **衰退突现**: "XXX"（20XX–20XX）突现已结束，说明该方向进入成熟期或已被整合。

3. **聚类持续时间**: 
   - 聚类 #X 持续时间最长（20XX–20XX），表明 XXX 是领域持续关注的经典议题。
   - 聚类 #X 出现时间最晚但增长迅速，反映 XXX 是最新涌现的研究方向。

#### 局限
- 时间切片为 1 年，可能无法精确捕捉跨年度突变事件。
- 突现检测对阈值敏感，Minimum Duration=2 年的设置可能遗漏短期热点。
- 2026 年数据可能不完整（取决于检索日期），当年趋势需谨慎解读。
```

## 图3: 作者合作网络图 / 机构合作地图

### 研究问题
**谁在推动这个领域？** —— 哪些作者/机构是核心贡献者？合作网络呈现什么结构？

### 解读框架（≥200字）

```markdown
#### 主要发现
1. **核心作者**:
   - [作者名]（机构: XXX）: 发文量 XX 篇，中心性 XX，是领域最高产/最具影响力的研究者。
   - [作者名]（机构: XXX）: 与 XXX、XXX 形成稳定合作三角，持续产出高被引论文。

2. **合作网络结构**:
   - 网络密度为 XX，呈现 "核心–边缘" 结构 / 多中心分散结构 / 紧密连接结构。
   - 存在 X 个主要合作群体，以 XXX（机构）为核心节点。
   - 跨机构合作占比 XX%，国际/国内合作以 XXX 为主导。

3. **机构分布**:
   - Top 3 高产机构: XXX（XX 篇）、XXX（XX 篇）、XXX（XX 篇）。
   - 中国/美国/欧洲机构占比分别为 XX%、XX%、XX%，显示 XXX 地区在该领域占主导地位。
   - 产业界参与度: XXX（企业）发文 XX 篇，反映产学研结合程度。

4. **新兴力量**: 
   - [作者/机构] 在 20XX 年后发文量显著增长，是领域新兴研究力量。

#### 局限
- 作者名消歧无法完全解决，同名同姓可能导致统计偏差。
- 机构标准化依赖映射表，部分机构合并可能不够精确。
- 合作网络仅反映合著关系，无法体现非正式学术影响（如学术交流、审稿等）。
```

## 表1: Top 10 里程碑论文列表

### 研究问题
**领域的奠基性文献有哪些？** —— 哪些论文在知识结构中起到关键作用？

### 指标说明

| 指标 | 含义 | 解读方式 |
|:---|:---|:---|
| **被引量** (Citations) | 总被引次数 | 反映文献的学术影响力 |
| **突现强度** (Burst Strength) | 突现检测中的强度值 | 反映文献在特定时期的关注度跃升 |
| **中介中心性** (Betweenness Centrality) | 网络中作为"桥梁"的程度 | 反映文献连接不同知识社群的能力 |
| **Sigma 值** (Σ) | 综合结构性和时间性新颖性的指标 | Σ > 1 表示该文献具有结构洞和时间前沿双重特征 |

### 表格模板

| 排名 | 第一作者 | 年份 | 标题 | 期刊 | 被引量 | 突现强度 | 中介中心性 | Sigma |
|:---|:---|:---|:---|:---|:---:|:---:|:---:|:---:|
| 1 | | | | | | | | |
| 2 | | | | | | | | |
| ... | | | | | | | | |

### 解读框架（≥200字）

```markdown
#### 主要发现
1. **综合影响力**: Top 10 论文中，Sigma > 1 的有 X 篇，表明这些文献不仅被大量引用，
   还在知识结构中起到桥梁作用，是领域的关键转折点。

2. **时间分布**: 
   - 早期奠基文献（20XX–20XX）: X 篇，奠定了 XXX 的理论/实验基础。
   - 近期高影响力文献（20XX–20XX）: X 篇，反映 XXX 技术突破带来的范式转变。

3. **主题分布**: Top 10 论文涵盖以下主题：
   - XXX 方向: X 篇，以 [作者, 年份] 为代表。
   - XXX 方向: X 篇，以 [作者, 年份] 为代表。

4. **关键文献解读**:
   - [作者, 年份]（Sigma = XX）: 中介中心性最高，连接了 XXX 和 XXX 两个研究方向，
     是该领域的知识枢纽。
   - [作者, 年份]（突现强度 = XX）: 在 20XX–20XX 年间突现，推动了 XXX 方向的快速发展。

#### 局限
- 四项指标均基于引用数据，可能遗漏尚未被广泛引用但具有潜在影响力的最新文献。
- Sigma 值计算依赖网络结构，不同参数设置可能影响排序结果。
- 单一文献列表无法全面反映领域知识基础，需结合共被引网络整体解读。
```
